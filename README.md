# RZD Monitor — Telegram-бот мониторинга билетов РЖД

Бот следит за наличием билетов на поезда РЖД на нужные даты и сразу присылает
уведомление в Telegram, когда появляются свободные места — удобно ловить
возвраты билетов на распроданные направления.

**Стек:** PHP 8 (strict types), Telegram Bot API (long polling), [visavi/rzd-api](https://github.com/visavi/rzd-api), Guzzle, Composer.

## Возможности

- Настройка маршрута прямо в чате: станции отправления и прибытия ищутся по названию через API РЖД.
- Несколько дат поездки сразу (`25.08.2026, 26.08.2026`).
- Фильтр по типу вагона: плацкарт, купе, СВ или любой.
- Интервал проверки в секундах; следующая проверка отсчитывается от конца предыдущей,
  поэтому медленный ответ РЖД не накапливает очередь запросов.
- Уведомление: поезд, время отправления и прибытия, вагон, класс, число мест, цена
  и ссылка на поиск на ticket.rzd.ru с подставленным маршрутом и датой.
- Клавиатура-меню: запуск/остановка мониторинга, статус, «проверить сейчас», настройки по умолчанию.

## Запуск

```bash
composer install
copy .env.example .env      # вписать токен бота от @BotFather
php bot.php
```

Команды: `/start`, `/status`, `/start_monitor`, `/stop_monitor`, `/test`, `/clear`.

## Файлы

- `bot.php` — Telegram-бот.
- `train-test.php` — консольная версия мониторинга (ввод маршрута с клавиатуры).
- `test.php`, `tls-test.php` — проверка доступа к API РЖД и TLS-соединения с ticket.rzd.ru.
